🎬 CineMatch.js

O CineMatch.js é um mini projeto feito em JavaScript e Node.js, desenvolvido no Visual Studio Code e executado pelo terminal.

A ideia é simular um aplicativo de streaming, com filmes, séries, usuários, busca de conteúdos, análise de compatibilidade e recomendações.

🚀 O que o projeto faz:

👤 Cadastro e perfil de usuário
🎬 Cadastro de filmes
📺 Cadastro de séries
📚 Catálogo de conteúdos
🔎 Busca de filmes e séries
🗂️ Filtro por gêneros
❤️ Análise de compatibilidade
⭐ Melhor recomendação
📋 Lista de títulos
🔞 Verificação de classificação indicativa
🖥️ Menu interativo no terminal
💻 Conceitos utilizados

Durante o projeto foram utilizados:

find() para buscar conteúdos
filter() para verificar gêneros em comum
map() para listar os títulos
reduce() para encontrar a melhor recomendação
every() para verificar a classificação indicativa
Callback para executar uma função passada como parâmetro
Closure para contar as análises realizadas
Promise e async/await para simular o carregamento do catálogo
Classes e herança para organizar filmes e séries
